Found and fixed during the drill
- Window opened before the agent wrote ipc.json: views showed an OS error and never retried. Views now reload when the agent
  becomes reachable; an unreachable agent reads "not reachable yet (starting or restarting)".
- Navigation scrolled away on long pages; views did not start at the top. Fixed (sticky nav, scroll to top on view change).
- Integration tests' unelevated launches through explorer.exe: launch folders were never deleted (525 in %TEMP%), and since
  Python 3.13 tempfile.mkdtemp (and pytest's temp tree) are owner-only, owner = Administrators from an elevated shell, so the
  unelevated Explorer/agent could not open them ("Windows cannot access the specified device, path, or file" dialogs Kevin
  saw after an unrelated Explorer crash). Launch and data folders now use a plain mkdir under %TEMP% (inherits the user's
  access) and are removed on exit.
